What happens in it

One real Compose app, one real Claude Code session, and Kane as the user. The agent session is also on a line by line replay.

  1. 01

    Set up

    ripcord init finds the databases and volumes and writes ripcord.yml with the app URL and plain English checks.

  2. 02

    Prove

    ripcord prove backs up, restores a throwaway copy, and Kane logs into the live app and the copy.

  3. 03

    Read the verdict

    PROVEN or LOSS, with each check's live and copy values side by side next to the row count.

  4. 04

    The agent tries a delete

    After ripcord hook install, the gate blocks the command until a fresh PROVEN exists.

  5. 05

    Verify and roll back

    ripcord verify has Kane reread the live app. ripcord rollback restores the proven backup and Kane checks it again.
